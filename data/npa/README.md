# Пример статусов НПА

Файл не является правовой базой. Колонки: `citation`, `status`, `replaced_by`.

Путь задаётся переменной `KP_NPA_CATALOG`. Без переменной каждая найденная ссылка остаётся «Не проверен — требуется ручная сверка». Совпавшая строка получает статус из файла и пометку «локальный перечень, не правовая база». Неизвестная ссылка не помечается как «действует».
