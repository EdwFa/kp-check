# Пример справочника ОКПД2

Файл `okpd2.example.csv` содержит три вымышленные строки и не является официальным справочником.

Колонки: `code`, `official_name`, `smp` (`yes` или `no`).

Путь к настоящему файлу задаётся переменной `KP_OKPD2_CATALOG`. Без переменной справочник не загружается, признак СМП не выводится.
