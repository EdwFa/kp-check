# Пример шаблона договора

`supply.example.docx` — вымышленный шаблон с плейсхолдерами и не является договором университета.

Плейсхолдеры: `{{name}}`, `{{qty}}`, `{{price}}`, `{{sum}}`, `{{specs}}`, `{{shelf}}`, `{{delivery}}`.

Боевой файл задаётся переменной `KP_CONTRACT_TEMPLATE`. Без неё кнопка генерации на странице «Решения» не показывается.
