# Пример запроса КП

`kp-request.example.docx` — вымышленный бланк и не является официальным запросом университета.

В нём реквизиты заказчика, условия поставки, оплаты и гарантии, а также таблица позиций. Дата отправки — плейсхолдер `{{sent_on}}`: пустая, пока её не ввести. Сборка не отправляет почту.
