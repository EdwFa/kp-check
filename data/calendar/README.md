# Пример производственного календаря

Файл не является официальным календарём. Списки `holidays` и `extra_workdays` пустые: праздники не выдуманы.

Путь задаётся переменной `KP_BUSINESS_CALENDAR`. Без файла срок в рабочих днях получает статус «недостаточно данных», дата не считается. Суббота не считается рабочим днём, пока она не указана в `extra_workdays`.
