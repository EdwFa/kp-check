# Пример перечня ограничений

Файл не является перечнем постановления Правительства РФ № 1875.

Колонки: `okpd2_prefix`, `measure` (`ban` или `restriction`), `source`. Необязательная колонка `requires` (`registry` или `st1`) говорит, какое поле КП нужно уточнить, если оно пустое.

Путь задаётся переменной `KP_NATIONAL_REGIME_CATALOG`. Без переменной проверка запрета не выполняется.
