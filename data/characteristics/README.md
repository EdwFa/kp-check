# Пример списка источников характеристик

Файл `allowlist.example.csv` вымышленный. Это не утверждённый перечень сайтов, и сам он не загружается.

Колонки: `host`, `source_class`. Класс бывает только «официальный сайт производителя», «государственный реестр» или «сторонний ресурс». Путь к настоящему файлу задаётся переменной `KP_CHARACTERISTIC_ALLOWLIST`. Поиск включается отдельно флагом `KP_CHARACTERISTIC_SEARCH`. Живой запрос идёт только на хосты этого файла. Без флага или без файла характеристика из интернета не запрашивается.
